# 사용된 컴퓨터 지식/스킬 — 서울 5대병원 응급실 혼잡도

## 프로젝트 요약

공공기관이 공개한 "공공데이터 API"로 서울 5대 병원의 응급실 여유병상 정보를 가져와 CSV로 저장하는 프로젝트. 자세한 진행 과정은 이 프로젝트의 README.md 참고.

## 사용한 지식/스킬

- API (다른 프로그램에게 정보를 물어보는 창구): 국립중앙의료원이 공개한 "응급의료기관 정보 조회" 창구에 병원 이름과 인증키를 보내면, 그 병원의 실시간 응급실 여유병상 수를 받아올 수 있다.
- 인증키(Service Key): API를 쓸 자격이 있다는 걸 증명하는 비밀번호 같은 문자열. 공공데이터포털에 가입하고 "활용신청"을 하면 받을 수 있다. 코드 안에 직접 적지 않고 `.env`라는 별도 파일에만 적어서, 실수로 인터넷(Git)에 올라가지 않게 한다.
- 기관코드(hpid): 병원마다 API 안에서 붙는 고유 번호. 병원 이름 대신 이 번호로 조회해야 정확해서, 먼저 "병원 이름 → 기관코드" 찾는 단계를 따로 만들었다.
- JSON (데이터를 사람도, 프로그램도 읽기 쉽게 정리한 텍스트 형식): API가 응급실 정보를 이 형식으로 돌려주면, 파이썬이 그 안에서 "응급실 여유병상 수" 같은 값만 뽑아 쓴다.
- CSV (엑셀처럼 표 데이터를 저장하는 단순한 파일 형식): 조회 결과를 표로 저장해서 엑셀로 바로 열어볼 수 있게 했다.
- 정적 HTML 대시보드: 파이썬이 조회 결과를 색깔 있는 카드(초록=여유, 노랑=혼잡, 주황=포화, 빨강=초과) 형태의 웹페이지 파일로 직접 찍어낸다. 서버 없이 더블클릭만으로 브라우저에서 열리고, 다시 실행하면 같은 파일을 덮어써서 새로고침만 하면 최신 상태로 보인다.
- 상태색(good/warning/serious/critical)과 아이콘+글자 라벨을 항상 같이 쓰는 원칙: 색맹이거나 흑백으로 봐도 상태를 알 수 있게, 색만으로 의미를 전달하지 않고 이모지·텍스트를 반드시 같이 붙였다.
- 디자인 토큰(design tokens): 회사가 자기 서비스 색깔·글꼴·여백·둥근 정도를 표(색상표, 크기표 등)로 정리해둔 것. Datarize라는 회사의 토큰 문서를 받아서, 그 안의 색상 값·폰트 이름·여백 숫자를 CSS 변수로 그대로 옮겨 담아 화면을 그 회사 스타일처럼 보이게 만들었다. 문서에 없는 값(예: 경고/위험 색)은 새로 지어내지 않고 기존 검증된 값을 유지했다.

## 다음에 비슷한 작업을 할 때 해야 할 점

- 외부 공공데이터 API를 쓸 때는 항목(파라미터) 이름과 응답 항목 이름이 문서와 실제가 다를 수 있으니, 실제로 한 번 호출해서 응답을 눈으로 확인한 뒤 코드를 마무리한다.
- 인증키가 없어도 코드가 사용자에게 무슨 파일을 만들어야 하는지 친절하게 알려주는지 먼저 확인한다(키 없이 한 번 실행해보기).

## 다음에 비슷한 작업을 할 때 주의할 점

- 병원 등 기관 이름은 API 안에 등록된 정식 명칭과 다를 수 있어서, 이름만으로 매칭하면 못 찾을 수 있다. 실행 후 결과를 꼭 눈으로 확인해야 한다.
- API가 "병원 하나만 딱 짚어서 조회하는" 파라미터(예: HPID)를 지원한다고 문서에 안 나와 있으면, 실제로는 그런 기능이 없을 수 있다. 처음엔 HPID로만 요청했더니 서버가 그 값을 무시하고 엉뚱한 병원 목록을 돌려줘서, 5개 병원 결과가 전부 똑같이 나오는 버그가 있었다. 지역(시도/시군구)으로 목록을 받은 뒤 원하는 병원의 고유번호로 직접 걸러내는 방식으로 고쳐서 해결했다. → 값이 이상하게 똑같이 반복되면 "요청 파라미터가 실제로 반영되고 있는지"부터 의심해본다.
